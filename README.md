### Project Description

**A Field Guide to Nearby Planets** is an interactive,
space-tourism-inspired web experience that lets users explore the Solar
System and discover completely useless---but fascinating---facts about
each planet. Users can click a planet to "fly" into a close-up view and
browse its facts.

The interface uses a mid-century space-poster aesthetic with orbit
rings, animated planets, a starfield background, and cinematic warp
transitions.

### The Problem (that doesn't exist)

People somehow manage to survive without knowing extremely specific and
completely unnecessary facts about planets.

For example: What happens if a planet's day is longer than its year?
Which planet smells like rotten eggs? And why would anyone need to know
that Saturn could theoretically float in a sufficiently enormous
bathtub?

This project solves that absolutely critical problem.

### The Solution (that nobody asked for)

We built an interactive planetary field guide where users can: - Explore
planets arranged around the Sun. - Click any planet to "fly" toward
it. - Read extremely useless facts about each planet. - Move between
planets using Previous/Next controls or navigation dots. - Return to the
Solar System overview. - Enjoy animated warp-speed transitions and a
responsive space-themed interface.

## Technical Details

### Technologies/Components Used

For Software: - **Languages:** HTML5, CSS3, JavaScript - **Frameworks:**

HTML/CSS/JavaScript - **Libraries:** Google Fonts (Archivo Black, Space
Grotesk, Fraunces) - **Tools:** HTML Canvas API, CSS
animations/transitions, JavaScript DOM APIs

For Hardware: - No special hardware required. - Any modern computer,
laptop, tablet, or smartphone with a modern web browser can run the
project.
